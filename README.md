# TikTok Claims Classification

An end-to-end machine learning project for classifying TikTok videos as **claims** or **opinions** using video-level and engagement-related features.

This project was completed as part of the **Google Advanced Data Analytics Professional Certificate** and demonstrates an end-to-end machine learning workflow from business problem definition to model evaluation and interpretation.

---

## 1. Project Overview

TikTok generates a large volume of user-generated content. For content moderation teams, distinguishing between factual claims and subjective opinions can help support content review and prioritization.

This project formulates the problem as a binary classification task:

- **Claim** — content that presents information that can potentially be verified.
- **Opinion** — content that expresses a personal view or judgement.

The objective is to develop a machine learning model that can accurately distinguish between the two classes.

---

## 2. Business Problem

Manual review of large volumes of content can require significant human resources.

A machine learning classification model could potentially support moderation teams by automatically identifying content that is more likely to contain claims and prioritizing it for further review.

The project therefore investigates:

> **Can machine learning accurately classify TikTok videos as claims or opinions based on available video and engagement features?**

---

## 3. Analytical Approach

The project follows an end-to-end machine learning workflow:

- Business Problem
- Data Understanding
- Data Cleaning
- Feature Engineering
- Train / Validation / Test Split
- Model Development
- Hyperparameter Tuning
